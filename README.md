# Exercicio de Cadastro e Quiz em Python

Estudo em Python com cadastro simples, confirmacao de senha e perguntas de multipla escolha pelo terminal.

## Visao geral

Este repositorio contem um exercicio introdutorio de logica de programacao. O script pratica entrada de dados, condicionais, repeticao com `while`, validacao de senha e acumulacao de pontuacao em um pequeno quiz.

## Problema resolvido

O projeto demonstra como combinar diferentes estruturas basicas de Python para criar um fluxo interativo no terminal.

## Principais funcionalidades

- Cadastro simples de dados informados pelo usuario.
- Calculo de idade com base no ano de nascimento.
- Confirmacao de senha.
- Repeticao enquanto a senha nao for confirmada.
- Perguntas de multipla escolha.
- Validacao basica de opcao.
- Soma de pontuacao.

## Como funciona

O programa pergunta se o usuario deseja iniciar, coleta dados basicos, valida a confirmacao de senha e apresenta perguntas com alternativas. Conforme as respostas, a pontuacao e atualizada.

## Tecnologias utilizadas

- Python
- Linha de comando
- Replit identificado por arquivos do repositorio
- Poetry identificado por `pyproject.toml`

## Arquitetura

Projeto simples com um unico script principal.

## Estrutura do projeto

- `main.py`: script com cadastro, validacao e quiz.
- `pyproject.toml`: configuracao Python/Poetry.
- `poetry.lock`: lockfile de dependencias.
- `replit.nix` e `.replit`: arquivos de ambiente Replit.
- `venv/`: ambiente virtual versionado no repositorio.

## Status

Projeto de estudo. Deve ser tratado como exercicio historico de aprendizagem, nao como sistema de cadastro real.

## Limitacoes conhecidas

- Nao armazena dados.
- Nao implementa seguranca real de senha.
- Contem conteudo didatico antigo e deve ser usado apenas como registro de aprendizado.
- O ambiente virtual esta versionado no repositorio.
